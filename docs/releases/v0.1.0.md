The first release of pgmux, a Postgres connection pooler in Go.

## ✨ Highlights

- 🔀 Session and transaction pooling for Postgres 14 to 17.
- 📝 Prepared statements in transaction mode, with no client changes. Prisma works without `pgbouncer=true`.
- 🔐 SCRAM-SHA-256 and MD5 authentication, with a userlist file or an `auth_query`.
- 🔒 TLS from clients and to Postgres, including `verify-full`.
- 📈 Prometheus metrics, an admin API, a live dashboard and a Grafana dashboard.
- ♻️ Config hot reload, pause and resume, graceful shutdown and cancel requests.

## 📊 Performance

With prepared statements and 100 or more clients, pgmux is 20% to 45% faster than PgBouncer 1.24.
With the simple protocol, PgBouncer is faster. See the [benchmarks](https://github.com/sanjeepan23/pgmux#-benchmarks).

## 📦 Install

- Binaries for Linux and macOS, amd64 and arm64, are attached below. Each archive has the dashboard.
- Docker image: `docker pull ghcr.io/sanjeepan23/pgmux:0.1.0`

## ⚠️ Known limitations

- Each client uses about 80 KB of memory.
- `PREPARE` and `EXECUTE` in SQL do not move between servers in transaction mode.
- No channel binding (`SCRAM-SHA-256-PLUS`).
